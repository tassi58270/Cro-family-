# Polices des images de partage

Copies statiques (TTF) de Bodoni Moda (graisse 500, taille optique 96) et d’Atkinson Hyperlegible Next (graisse 500), pour les images de partage générées par `next/og`, qui ne lit pas le WOFF2.
Les pages, elles, chargent les polices par `next/font` (`lib/design/fonts.ts`).
